# ⚽ Football Voting Management System

A command-line Football Voting Management System built with Python.

This project allows administrators to manage voters, collect votes for football players, display rankings, and announce the winner based on total votes.

---

# Features

- 👤 Add new users
- ❌ Delete existing users
- 🗳️ One vote per registered user
- 🏆 Display election winner
- 📊 Show player rankings
- 📋 View all registered users
- 🔒 Prevent duplicate user IDs
- 🚫 Prevent users from voting multiple times
